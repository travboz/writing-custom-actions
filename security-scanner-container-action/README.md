# Security Scanner - Container action

## What does this action do?

This action runs a security scan on python files and package dependencies in the specified path. It then generates a report of vulnerabilities that meet a determined threshold.

## Inputs

### `scan-path`

**Not Required** The path to scan for vulnerabilities. Default `"."`.

### `severity-threshold`

**Not Required** Minimum severity threshold to report (low, medium, high, critical). Default `"medium"`.

## Outputs

### `vulnerabilities-found`

The number of vulnerabilities found that meet, or surpass, the threshold.

### `report-path`

The path to the report generated by the scanner.

## Example usage

```yaml
- name: Run security scan
  uses: travboz/security-scanner@v1
  with:
    scan-path: ./src
    severity-threshold: high
```
