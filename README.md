## What it does

One of the features of GitHub Actions is the ability to create our own custom actions. These come in three flavours:

- Docker Container Actions
- JavaScript Actions
- Composite Actions

This repo contains an implementation of each of the types.

The motivation here is education because I am currently progressing towards completing the Actions certification.

So, I figure building some custom actions is prudent.
