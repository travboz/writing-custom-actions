## What it does

One of the features of GitHub Actions is the ability to create our own custom actions. These come in three flavours:

- Docker Container Actions
- JavaScript Actions
- Composite Actions

This repo contains an implementation of each of the types.

The motivation here is education because I am currently progressing towards completing the Actions certification.

So, I figure building some custom actions is prudent.

> NOTE: The layout of this README was **generated by Claude** - because I wanted to have a consistent structure to my README.md files. This is a start.

## Getting started:

Pick an action from this repo, and use it in your workflow like this.

See each `README.md` and `action.yaml` file contained in each action for information on how to use.

## Usage example

Using the `Security Scanner` container action in a workflow:

```yaml
- name: Run security scan
  uses: your-username/security-scanner@v1
  with:
    scan-path: ./src
    severity-threshold: high
```
